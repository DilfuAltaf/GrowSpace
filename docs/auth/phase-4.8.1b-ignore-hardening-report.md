## 1. Exact `.gitignore` Additions & Technical Justifications

The root `.gitignore` was updated with the following additive rules:

| Section | Added Pattern | Technical Justification |
|---|---|---|
| **Builds** | `.turbo/` | Turbopack compilation and task cache directory generated by Next.js 16. |
| **Environment** | `*.env`<br>`*.env.local` | Shields environment files without leading dots (e.g. `staging.env`, `local.env`) and explicit local overrides while preserving `!.env.example`. |
| **Keys & Credentials** | `*.pem`<br>`*.key`<br>`*.crt`<br>`*.cert`<br>`*.p12`<br>`*.pfx`<br>`*credentials*.json` | Blocks generic SSL certificates, private keys, PKCS#12 bundles, and Google Cloud / service account credential JSON files from entering version control. |
| **Testing** | `test-results/`<br>`playwright-report/`<br>`blob-report/` | Pre-emptively shields Playwright and browser end-to-end test run artifacts, failure screenshots, traces, and HTML reports. |
| **Editors & OS** | `Desktop.ini`<br>`desktop.ini`<br>`ehthumbs.db`<br>`$RECYCLE.BIN/`<br>`*.swp`<br>`*.swo`<br>`*~` | Ignores Windows Explorer folder customization files, thumbnail caches, recycle bins, and editor swap/backup files. |
| **Neon CLI State** | `.neon/`<br>`.neon.*`<br>`**/.neon/**` | Prevents local Neon CLI state directories, credential caches, or branch metadata from being tracked, while safely allowing source files like `neon.ts`. |
